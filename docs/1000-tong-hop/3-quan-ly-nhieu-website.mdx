# Quản lý nhiều website

## Lợi ích quản lý nhiều website trên Subiz {#loi-ich-quan-ly-nhieu-website-tren-subiz}

Subiz hỗ trợ bạn quản lý và tương tác khách hàng trên nhiều website chỉ với một nền tảng duy nhất. Bạn có thể:

- Theo dõi toàn bộ khách truy cập trên tất cả website.
- Trả lời nhanh chóng tất cả tin nhắn từ bất kỳ website nào.
- Hiển thị cửa sổ chat riêng cho từng website.
- Tùy chỉnh Bot tự động gửi tin nhắn riêng biệt cho từng website.
- Phân chia hội thoại của từng website tới đúng nhân viên phụ trách.

## Hướng dẫn cài đặt {#huong-dan-cai-dat}

- Bước 1: Tích hợp thêm website
- Bước 2: Thiết kế cửa sổ chat riêng cho từng website
- Bước 3: Phân chia hội thoại khách nhắn tin của từng website
- Bước 4: Bot tự động trả lời theo từng website
- Bước 5: Thống kê hội thoại từng website

### Bước 1: Tích hợp thêm website {#buoc-1-tich-hop-them-website}

Tại [dashboard làm việc sau khi đăng nhập Subiz](https://app.subiz.com.vn/convo), làm theo các bước sau:

- Nhấn biểu tượng bánh răng ở góc trên bên phải màn hình để tới trang cài đặt
- Chọn tích hợp <b>Website</b> ở sidebar bên trái
- Nhấn <b>+ Cài lên website</b> ở góc phải màn hình
- Điền tên miền website `domain.com`
- Sao chép mã nhúng Subiz và tới trang quản trị website dán mã trong thẻ `body`.

### Bước 2: Thiết kế cửa sổ chat riêng cho từng website {#buoc-2-thiet-ke-cua-so-chat-rieng-cho-tung-website}

Khi bạn kinh doanh nhiều thương hiệu sản phẩm - dịch vụ trên nhiều website khác nhau. Bạn có thể tạo cửa sổ chat hiển thị thương hiệu riêng của từng website.

Hướng dẫn tạo thêm agent:

- Mở [Cài đặt Website](https://app.subiz.com.vn/settings/website)
- Chọn <b>Chỉnh sửa cửa sổ chat</b> tương ứng với mỗi website

- Lựa chọn thay đổi màu sắc, kích thước, vị trí… như thông thường

![](https://r2s.subiz.net/file/acpxkgumifuoofoosble/5b2c51df015883ad16870dda4d7560e7d0b730b497c277fbea0cc63e8b4cdf42)

- Chọn Đối tượng mục tiêu nếu bạn muốn đặt cửa sổ chat chỉ hiển thị trên những trang con cụ thể trên website

- Bấm Lưu thay đổi để hệ thống ghi nhận thiết kế mới

### Bước 3: Phân chia hội thoại khách nhắn tin theo từng website {#buoc-3-phan-chia-hoi-thoai-khach-nhan-tin-theo-tung-website}

Khi có nhiều website, bạn có thể thiết lập khách hàng nhắn tin từ website nào sẽ được chuyển cho đúng nhóm nhân viên phụ trách website đó. Vì vậy, nhân viên chỉ xem được tin nhắn của website phụ trách.

Bạn sẽ [cài đặt rule phân phối](https://app.subiz.com.vn/settings/rule-setting) tự động chia tin nhắn của từng website:

- Nhấn biểu tượng bánh răng ở góc trên bên phải màn hình để tới trang cài đặt
- Vào cài đặt [Rule phân phối](https://app.subiz.com.vn/settings/rule-setting)
- Tạo Rule mới thuộc loại <b>Tin nhắn</b>, với điều kiện nguồn là \[<b>Link website</b>\], rồi cài đặt phân phối đến <b>agent phụ trách</b>.
- Hoặc chỉnh sửa Rule hiện có cùng loại để thêm kênh Website.

Ví dụ có 3 website thì bạn tạo 3 Rule tương ứng chia khách của từng website

### Bước 4: Bot tự động trả lời theo từng website {#buoc-4-bot-tu-dong-tra-loi-theo-tung-website}

Bot tự động chào đón và trả lời riêng cho từng website.

- [Tạo bot mới](https://app.subiz.com.vn/bots)
- Tại mục 2 cài đặt, chọn “Trên các website có chứa” và điền “tên miền website”

### Bước 5: Thống kê hội thoại của mỗi website {#buoc-5-thong-ke-hoi-thoai-cua-moi-website}

Vào [Thống kê hội thoại](https://app.subiz.com.vn/new-reports/convo), chọn Theo website để xem chi tiết số lượng hội thoại từ từng nguồn.
